# Project notes

- Site for The Sweet Spot (dessert shop, Tripoli). EN + AR with full RTL. Pages: landing, about, contact, order (menu + cart). No payments: orders are saved to Supabase.
- Design references live in `design_handoff_sweet_spot_site/` (start with its `README.md`) and `mockups/`. They are prototypes, not code to copy; recreate the design in React.
- Run `npm run lint`, `npm run typecheck` and `npm run build` before committing.
